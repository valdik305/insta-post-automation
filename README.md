# 📸 Instagram Auto-Poster: Psychology & Philosophy

Полностью автоматизированный конвейер для создания и публикации эстетичных каруселей с цитатами в Instagram. Скрипт сам генерирует философские мысли с помощью ИИ, создает уникальные фоны, накладывает текст, подбирает спокойную музыку и публикует посты.

## ✨ Возможности
```markdown
- 🎨 **Генерация изображений:** Создает атмосферные фоны. Фон автоматически меняется каждые 5 постов (состояние хранится в `data/bg_index.txt`).
- 📦 **Карусели:** Скрипт строго генерирует 5 цитат за один запуск, собирая их в одну карусель.
- 🧠 **Автогенерация контента:** Использует бесплатный API Pollinations для создания 5 уникальных цитат.
- 🎵 **Интеграция с Reels:** Автоматически подбирает случайную спокойную музыку и публикует карусель, чтобы она попадала в рекомендации Reels.
- 🤖 **Полная автоматизация:** Один скрипт (`run_all.py`) запускает весь процесс от генерации текста до публикации.
- 🔒 **Безопасность:** Все пароли хранятся в `.env` файле и защищены от публикации в Git.

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/ТВОЙ_НИК/ТВОЙ_РЕПОЗИТОРИЙ.git
cd ТВОЙ_РЕПОЗИТОРИЙ
```

###  2. Настройка окружения

#### Создайте виртуальное окружение и установите зависимости:

```bash
python -m venv .venv
source .venv/bin/activate  # Для Windows: .venv\Scripts\activate
pip install -r requirements.txt
```
### 3. Настройка секретов (.env)
#### Создайте файл `.env` в корне проекта и добавьте свои данные:
```env
IG_USERNAME=ваш_логин_без_собаки
IG_PASSWORD=ваш_пароль
CAPTION=Текст поста и хештеги
# Ключ для бесплатного и стабильного ИИ (получить: https://enter.pollinations.ai)
POLLINATIONS_API_KEY=sk_ваш_ключ
```
### 4. Шрифты

#### В проекте уже используются шрифты Montserrat и Playfair Display. Они лежат в папке fonts/. Если вы хотите их заменить, просто положите свои .ttf файлы туда и обновите названия в main.py.

#### 🎮 Использование

#### Ручной запуск (Тестирование)

Чтобы запустить весь пайплайн один раз (Генерация цитат -> Генерация картинок -> Публикация), выполните:

```bash
python run_all.py
```
#### Автоматический запуск (Планировщик)

Чтобы посты выходили каждые 4 часа, настройте cron (macOS/Linux).
Откройте терминал и введите ``` crontab -e.``` Добавьте строку (замените пути на свои):

```bash
0 */4 * * * cd /путь/к/проекту && /путь/к/проекту/.venv/bin/python run_all.py >> logs/cron.log 2>&1
```
